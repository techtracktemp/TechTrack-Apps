# TechTrack Apps

App pages for the TechTrack web app and the TechTrack Vendor Portal, served by GitHub Pages.

- techtrack/ : TechTrack app (MCR staff)
- vendor-portal/ : TechTrack Vendor Portal app (vendors)

Each app page opens the live Apps Script web app full screen. The web app links live in each folder's config.js.
